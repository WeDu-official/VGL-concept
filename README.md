# VGL — Verified Gossip Ledger

**A peer-to-peer value transfer protocol that doesn't need a global ledger.**

VGL is a complete rethinking of how decentralized payments can work. Instead of forcing every node to agree on a single global history (like Bitcoin or Ethereum), VGL uses **local verification** and **enode operation commites* and status managed vis **PPOs** to transfer value instantly, and with near-zero cost.
